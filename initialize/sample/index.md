# Welcome

This is the home page of your project: the `index.md` in the project's root folder. It is the start page of the website and does not appear in any printed book. It is the only page that needs no `order:` in its front matter.

Every folder below the root that holds pages is a **topic**. Each topic becomes a book of its own when you render a print format, and an entry in the website's menu. This sample has a single topic, the [Handbook](/handbook/).

To see the website while you write, run `folio preview` and open the address it prints. To edit the pages in your browser, run `folio web`.
