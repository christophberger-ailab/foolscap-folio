# Welcome

This is the home page of your project: the `index.md` in the project's root folder. It is the start page of the website and does not appear in any printed book. It is the only page that needs no `order:` in its front matter.

Every folder below the root that holds pages is a **topic**. Each topic becomes a book of its own when you render a print format, and an entry in the website's menu. This demo has two: the [Handbook](/handbook/) explains what a page's place in the tree means, and the [Showcase](/showcase/) shows folio's Markdown extensions.

`folio.yml` sets up a website and a handout (DOCX and PDF), and two audiences, `everyone` and `experts`: `folio render` writes each topic for each audience in each format.

To see the website while you write, run `folio preview` and open the address it prints. To edit the pages in your browser, run `folio web`.
