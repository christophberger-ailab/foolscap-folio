# Pages

This page is a Markdown file in a section folder, so it is a **chapter**. A chapter's headings render as written, from level 1 to level 6.

## Front matter

Each page starts with front matter between two `---` lines. `title` names the page in the menus, and `order` puts it among its neighbors.

## Callouts

::: {.callout-tip}
Callouts like this one draw attention to a tip, a note or a warning. They work in the website and in print.
:::

## Deeper levels

Folders inside a chapter folder go one level deeper, and folio lowers their headings by a level each. Keep the tree shallow: below heading level 6 there are no headings left, and folio warns about it.
