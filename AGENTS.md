# Information for agents

## The repo

This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.

## Development

- Always use red/green TDD in the process

## Programming in Go

- Use idiomatic Go
- Use a minimailistic stlye: Write concise code, don't repeat yourself (except where a little repetition outweighs the drawbacks)
- Write code in accordance with the Go proverbs
- Use the standard library first; reach out for third-party libraries only if the standard library isn't sufficient for the task
- Do not add abstraction layers unless necessary; most probably, You Ain't Gonna Need It (YAGNI)
 
## Testing and verifying

- Test for security: use tools like govulncheck, gosec, golangci-lint, etc. if available. Use your own security knowledge to avoid security issues when writing code and find them when reviewing code.
